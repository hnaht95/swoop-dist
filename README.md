# Swoop — distribution

Public distribution channel for the Swoop macOS app (source is private).

- **Download:** https://swoop.io.vn/download, or [Releases](https://github.com/hnaht95/swoop-dist/releases) → `Swoop-<version>.dmg`
- **Auto-update:** `appcast.xml` on `main` mirrors https://swoop.io.vn/appcast.xml, for builds from July 2026 that still read their feed from here.

Universal (Intel + Apple Silicon), macOS 14+, signed & notarized by 3H VIETNAM TRADING AND SERVICE JOINT STOCK COMPANY.
